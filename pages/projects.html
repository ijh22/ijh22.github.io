Deadwood

A Java recreation of the Deadwood board game utilizing the MVC Architecture. Built with a decoupled core game logic that drives two interchangeable views: a text-based terminal interface and a graphical Swing UI. The model governs the board state and rules, the controller handles player input and turn flow, and the view strictly renders the game state.

  • Java
  • Java Swing
  • MVC
  • Object-Oriented Design
